# Ryan Mondega - Portfolio

A modern, interactive portfolio website showcasing web development work and experience.

- Interactive terminal-style interface
- Project showcase with detailed views
- Professional journey timeline
- Contact form
- Responsive design
- Custom theme system

- HTML5
- CSS3
- Vanilla JavaScript

Simply open `index.html` in a web browser to view the portfolio.
